Transformer推理基础

Attention 核心原理

  • Q（Query）：查询什么信息。
  • K（Key）：用于与 Query 计算匹配分数。
  • V（Value）：提供实际被汇总的信息。
  • Q/K/V 由 Hidden States 经过不同的线性投影得到。

Scaled Dot-Product Attention

  • sqrt(d)：控制分数尺度，避免 Softmax 过早饱和。
  • softmax(dim=-1)：沿 Key 维度归一化。
  • Attention 输出上下文向量，不直接生成 Token。

Shape（标准多头注意力）

B=Batch，H=Head 数，D=Head 维度。

输出位置数由 Q 决定，输出向量维度由 V 决定。

Causal Mask（因果掩码）

作用：确保当前 Token 只能访问自己和历史 Token，防止未来信息泄漏。

  • 行对应 Query，列对应 Key。
  • 本项目约定 True = 允许，False = 禁止。
  • Mask 在 Softmax 前应用，禁止位置填 -inf，使最终权重为 0。

Broadcasting

KV Cache 下的长方形 Mask

适用于 [历史缓存, 本次新增] 连续排列的情况。

  • Prefill：整段 Prompt 并行计算，需要保证因果性。
  • 单 Token Decode：Query 只有一个，若 K/V 仅包含历史及自身，可省略显式 Causal Mask。
  • 因果性不变量：修改未来 Token，不应影响过去位置的输出。

Multi-Head Attention

目的：让多个 Attention Head 在不同表示子空间中分别计算注意力，再合并结果。

Shape 变化

关键 API

  • view()：在内存布局允许时重新解释 Shape。
  • transpose()：交换维度。
  • reshape()：改变 Shape，必要时复制数据。
  • nn.Linear()：对最后一维执行线性投影。

MHA / GQA / MQA

类型 KV Head 数
MHA 与 Q Head 数相同
GQA 多个 Q Head 共享一组 KV Head
MQA 所有 Q Head 共享一组 KV Head

KV Cache 大小取决于 KV Head 数，不一定等于 Q Head 数。

Transformer 整体结构

组件职责

组件 作用
Embedding Token ID 转换为向量
Position Encoding 注入位置信息
Attention 融合上下文信息
MLP 对每个位置进行非线性特征变换
LayerNorm / RMSNorm 归一化隐藏表示
Residual 保留原始信息，辅助深层网络训练
LM Head 隐藏向量映射到词表 Logits

整体 Shape

  • Decoder-Only：采用因果自注意力的模型架构。
  • Prefill / Decode：推理执行阶段，与 Decoder-Only 不是同一个概念。

与 vLLM / AI Infra 的联系

朴素生成的问题

KV Cache 优化

  • 每个 Transformer Layer 都有自己的历史 K/V。
  • KV Cache 保存历史 Key/Value，不保存完整 Attention 权重矩阵。
  • PagedAttention 重点优化 KV Cache 的分页存储与访问。
  • Scheduler / Continuous Batching 负责高效组织多个推理请求。
  • 真实 vLLM 还会使用优化 Kernel、GQA、RoPE、RMSNorm 等技术。

核心认识：模型计算逻辑是基础；推理引擎重点优化重复计算、KV Cache 内存、并发调度与执行效率。
